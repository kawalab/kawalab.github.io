# 河並研究室 Web Site

金沢工業大学 情報理工学部 情報工学科 河並研究室のWebサイトです。  
研究テーマ、研究室選択を考える学生向けの情報、大学院進学への流れ、活動履歴、研究業績、問い合わせ先などを掲載しています。  
このサイトはOpenAIのChat GPT 5.5を用いて大部分を作成しています。

## 公開サイト

https://kawalab.github.io/

## 研究室について

河並研究室では、IoT・センサ・AI・ネットワーク・教育工学を活用し、人の行動や学びを支援する情報システムの研究開発に取り組んでいます。

主な研究領域は以下です。

- 運動解析・ウェアラブルセンシング・モーションキャプチャ
- 歩容解析・インソール型センサ
- センサネットワーク・IoT
- STEAM教育・プログラミング教材開発
  - プロトタイピング
  - おもちゃハック
  - ドローンプログラミング
  - eSports教材
- 小型ドローン制御
- eSports・生体情報分析・プレイ動画解析

## サイト構成

このWebサイトは、GitHub Pagesで公開する静的サイトです。

- `index.html`  
  研究室トップページです。研究室の概要、研究テーマ、研究室配属について、問い合わせ先を掲載しています。

- `profile.html`  
  河並崇の自己紹介ページです。プロフィール、担当科目、職歴、学外活動などを掲載しています。

- `activity.html`  
  研究室の活動履歴ページです。学生の成果、年度別活動記録、代表的な研究業績を掲載しています。

- `README.md`  
  このリポジトリの説明ファイルです。GitHub上でリポジトリを開いたときに表示されます。

- `.nojekyll`  
  GitHub PagesでJekyll処理を無効化するためのファイルです。

- `.gitignore`  
  Git管理から除外するファイルを指定するためのファイルです。

- `assets/`  
  CSS、JavaScript、画像などのWebサイト用ファイルを格納します。
