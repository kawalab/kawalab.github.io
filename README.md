# 河並研究室 Web Site

金沢工業大学 情報理工学部 情報工学科 河並研究室のWebサイトです。  
研究テーマ、研究室選択を考える学生向けの情報、大学院進学への流れ、活動履歴、研究業績、問い合わせ先などを掲載しています。  
このサイトはOpenAIのChatGPT / Codexを利用して作成しています。

## 公開サイト

https://kawalab.github.io/

## 研究室について

河並研究室では、IoT・センサ・AI・ネットワーク・教育工学を活用し、人の行動や学びを支援する情報システムの研究開発に取り組んでいます。

主な研究領域は以下です。

- 運動解析・ウェアラブルセンシング・モーションキャプチャ
- 歩容解析・インソール型センサ
- センサネットワーク・IoT
- STEAM教育・プログラミング教材開発
  - プロトタイピング
  - おもちゃハック
  - ドローンプログラミング
  - eSports教材
- 小型ドローン制御
- eSports・生体情報分析・プレイ動画解析

## サイト構成

### トップページの新着情報

`index.html` の `home-news-list` にお知らせを追加します。新しい項目を先頭に置き、トップには直近3〜5件程度を掲載します。日付・種類・短い案内文・リンク先を更新してください。見学終了後は案内を外すか、終了したことが分かる文面に変更します。活動履歴の更新を知らせる場合は、先に `activity.html` の内容も更新します。

以下は入力用の例です。日付や日程は確定した内容に置き換えてから掲載してください。日付のない常設リンクでは、日付欄を「ご案内」にできます。

本文は必ず `<p class="home-news-text">...</p>` で囲み、その中にリンクを入れます。全文リンク・一部だけのリンク・リンクなしのいずれも同じ構造を使えます。`li` の直下に本文やリンクを分けて置くと、別々の列として配置されるため避けてください。

```html
<li class="home-news-item">
    <time class="home-news-date" datetime="YYYY-MM-DD">YYYY.MM.DD</time>
    <span class="home-news-category">見学案内</span>
    <p class="home-news-text">確定した研究室見学の日程・案内。ご相談は<a href="#contact">問い合わせ先</a>へ。</p>
</li>
```

このWebサイトは、GitHub Pagesで公開する静的サイトです。

- `index.html`  
  研究室トップページです。研究室の概要、研究テーマ、研究室配属について、問い合わせ先を掲載しています。

- `profile.html`  
  河並崇の自己紹介ページです。プロフィール、担当科目、職歴、学外活動などを掲載しています。

- `activity.html`  
  研究室の活動履歴ページです。学生の成果、年度別活動記録、代表的な研究業績を掲載しています。

- `README.md`  
  このリポジトリの説明ファイルです。GitHub上でリポジトリを開いたときに表示されます。

- `.nojekyll`  
  GitHub PagesでJekyll処理を無効化するためのファイルです。

- `.gitignore`  
  Git管理から除外するファイルを指定するためのファイルです。

- `assets/`  
  CSS、JavaScript、画像などのWebサイト用ファイルを格納します。
