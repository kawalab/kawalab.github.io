# 河並研究室 Web Site

金沢工業大学 情報理工学部 情報工学科 河並研究室のWebサイトです。  
研究テーマ、研究室選択を考える学生向けの情報、大学院進学への流れ、活動履歴、研究業績、問い合わせ先などを掲載しています。

## 公開サイト

https://kawalab.github.io/

## 研究室について

河並研究室では、IoT・センサ・AI・ネットワーク・教育工学を活用し、人の行動や学びを支援する情報システムの研究開発に取り組んでいます。

主な研究領域は以下です。

- 運動解析・ウェアラブルセンシング・モーションキャプチャ
- 歩容解析・インソール型センサ
- センサネットワーク・IoT
- STEAM教育・プログラミング教材開発
  - プロトタイピング
  - おもちゃハック
  - ドローンプログラミング
  - eSports教材
- 小型ドローン制御
- eSports・生体情報分析・プレイ動画解析

## サイト構成

このWebサイトは、GitHub Pagesで公開する静的サイトです。

- `index.html`  
  研究室トップページです。研究室の概要、研究テーマ、研究室で経験できること、研究室選択から大学院進学への流れ、代表的な成果、問い合わせ先を掲載しています。

- `profile.html`  
  河並崇の自己紹介ページです。プロフィール、担当科目、職歴、学外活動などを掲載しています。

- `activity.html`  
  研究室の活動履歴ページです。学生の成果、年度別活動記録、代表的な研究業績を掲載しています。

- `README.md`  
  このリポジトリの説明ファイルです。GitHub上でリポジトリを開いたときに表示されます。

- `.nojekyll`  
  GitHub PagesでJekyll処理を無効化するためのファイルです。

- `.gitignore`  
  Git管理から除外するファイルを指定するためのファイルです。

- `assets/`  
  CSS、JavaScript、画像などのWebサイト用ファイルを格納します。

## 更新方法

### トップページを修正する場合

`index.html` を編集します。

主なセクションは以下です。

- トップメッセージ
- 研究室について
- 研究テーマ
- 研究室で経験できること
- 研究室選択から大学院進学への流れ
- 代表的な成果
- 問い合わせ

トップページは、研究室を初めて見る学生や学外の方に向けた入口ページです。  
詳細なプロフィールや活動記録は、それぞれ別ページに分けています。

### 河並の自己紹介を修正する場合

`profile.html` を編集します。

主な内容は以下です。

- 基本プロフィール
- 研究・教育の軸
- 担当科目
- 職歴
- 学外活動

### 活動履歴・業績を修正する場合

`activity.html` を編集します。

主な内容は以下です。

- 学生の成果
- 年度別活動記録
- 代表的な研究業績

活動記録や論文情報を追加する場合は、このページに追記してください。

### デザインを修正する場合

`assets/css/style.css` を編集します。

主な色は `:root` 内のCSS変数で管理しています。

- `--main`
- `--main-dark`
- `--main-soft`
- `--accent`
- `--accent-soft`

### 画像を差し替える場合

`assets/images/` 内の画像を差し替えます。  
ファイル名を変更した場合は、HTML側の `<img src="...">` も修正してください。

## GitHub Pages

このサイトは GitHub Pages で公開しています。

設定は以下を想定しています。

- Settings > Pages
- Source: Deploy from a branch
- Branch: main
- Folder: / root

`index.html` がトップページとして表示されます。

## 編集時の注意

- リポジトリ直下に `index.html` を置いてください。
- `assets/` フォルダもリポジトリ直下に置いてください。
- `index.html`、`profile.html`、`activity.html` のファイル名を変更すると、メニューリンクも修正が必要です。
- 画像を追加する場合は、ファイルサイズが大きくなりすぎないようにしてください。
- 活動記録や業績は、トップページではなく `activity.html` に追加してください。
- 河並のプロフィール情報は、トップページではなく `profile.html` に追加してください。
- 大学名、所属、居室、メールアドレスなどの基本情報を変更する場合は、トップページ、プロフィールページ、活動履歴ページのフッターや問い合わせ箇所も確認してください。

## 運用方針

このサイトは、研究室のメインWebサイトとして運用することを想定しています。

トップページでは、研究室の全体像と研究室選択を考える学生向けの導線を示します。  
詳細な活動履歴や研究業績は `activity.html` にまとめ、河並の個人プロフィールは `profile.html` に分けています。
